# Statistical Analysis Plan

Write the exact canonical artifact requested by the invocation contract.

## Procedure

1. Read the selected idea, domain methodology, experiment plan, data description, and publication profile.
2. Define the estimand or primary evaluation quantity before choosing a test.
3. State the independent analysis unit and account for grouping, repeated measures, clustering, censoring, or batch structure.
4. Prespecify primary and secondary endpoints, uncertainty intervals, multiplicity control, missing-data handling, exclusion rules, diagnostics, sensitivity analyses, and stopping rules.
5. For predictive studies, include split integrity, repeated seeds or resampling, paired comparisons, calibration, and external validation. For non-predictive studies, use the profile-appropriate inferential model.
6. If inputs are unknown, write a decision rule and mark it unresolved. Never invent sample size, power, effect, p-value, or result.
