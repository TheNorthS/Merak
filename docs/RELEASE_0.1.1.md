# 0.1.1 初始公开测试版

这是本仓库的初始发布版本，提供科研工作台界面、13 节点工作流和完整技能能力，
包含工具反馈、报告修订、检查点恢复、文献证据和论文产物生成能力。

## 发布前开发验证

以下记录来自版本号统一前的开发候选。版本号调整不代表重新完成安装包验收；
0.1.1 安装器须手动构建并运行随包检查，历史同名安装器不能代替本次构建。

- 一个本地计算研究项目通过全部 13 个节点，生成论文、图表、实验记录、审查记录、
  演示稿及可编辑源文件。实际执行 36 组模拟实验，独立重算 168 项统计行。
- 168 项本地回归、类型检查、代码规范、前端构建通过。
- Windows x64 包的后端启动、94 个技能加载、绘图、身份验证、恢复指纹检查通过。
- 桌面工作区、聊天及工作流连接、断线恢复和设置保存通过。
- 安装器解出的 2,203 个文件与测试目录一致，解出后的程序启动检查通过。

## 尚未满足的正式稳定版门槛

完成的研究任务经过开发修复与恢复，不是同一冻结版本三个新项目连续无干预
成功的证明。模型网关曾返回 HTTP 502、503 和超时，相关记录保留。
未覆盖用户旧安装进行实际升级验证；未完成所有外部服务和 GPU 环境验收。

科研交付是可审查草稿，保留审稿与审计中的科学限制，不表示具备投稿资格。
验证论文超过原目标页数。请勿把本版本标为工业级稳定性验收已全部完成。

安装器和校验文件作为 GitHub Release 附件分发，不提交到源码 Git 历史。
具体构建步骤见 [发布指南](RELEASING.md)，稳定性门槛见
[稳定性验收](STABILITY_ACCEPTANCE.md)。
