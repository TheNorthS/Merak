# Merak 使用指南

## 安装和第一次启动

安装 Windows x64 版本后启动。安装版内置后端，首次启动会在应用用户数据目录创建配置与数据库。桌面模式自动建立本机访问身份，无需输入管理员账号或密码；启动时等待本地服务连接后自动进入工作区。连接异常时可点击“重新连接”或“重启本地服务”。Web 部署需要配置用户认证。

启动页以星芒与轨道动画显示“载入界面 → 启动本地服务 → 连接工作区”的阶段，跟随真实连接状态更新。启动页沿用已保存的深色或白色主题，并尊重系统的减少动态效果设置。服务就绪后立即进入工作区。

创建或打开有写权限的科研项目目录。项目 `.merak/` 保存检查点、会话、日志及版本记录，备份项目时应一并保留。

## 配置与研究

1. 打开设置中的模型配置，填写接口、密钥及模型名称，并完成连接测试。
2. 填写研究方向、输入材料及目标会议，选择可审查草稿或更严格的交付目标。
3. 配置实验执行目标及其环境；按需启用 Zotero、Obsidian、Overleaf 等集成。
4. 主动启动全流程或指定节点，通过工作流面板查看进度、日志和产物。

可审查草稿允许明确披露未完成的实证，投稿目标要求更严格的证据与审查条件。

## 中断与恢复

模型超时、工具失败或主动取消后，当前产物和中断信息会保留。先修复模型设置、环境或输入，再点击恢复。恢复使用检查点与依赖校验，不会自动改用固定实验骨架。

## 完成后的修改

已完成工作流保持完成状态，局部修改使用右侧对话框：

1. 打开对话框，选择编辑模式，说明目标文件和修改要求。
2. 检查模型提出的差异，批准后写入文件。
3. 系统单独保存局部修订，保留完成版本与修改前内容；新修改不会自动获得原稿的科学审查结论。
4. 需要重新实验、审查或执行工作流时，由你主动发起。

右上角 **×** 关闭面板，再点击侧边栏对话图标打开；当前会话、待批准修改和输入草稿保留。

## 外部工具

- **LaTeX**：安装 TeX Live 或 MiKTeX，确认 `latexmk`、TeX 引擎和会议模板可用。
- **本地实验**：设置 `MERAK_EXPERIMENT_PYTHON` 指向独立实验环境，按项目安装训练依赖。
- **SSH**：配置地址、认证、远程项目路径、实验命令和环境。
- **Vast.ai / Modal**：配置凭据、资源和运行环境，确认费用范围后启动实验。
- **Zotero / Obsidian**：配置文献库和 Vault 路径，在研究设置中启用。
- **Overleaf**：配置项目访问和 Git 同步，先处理同步冲突以保留并发修改。

## 日志与问题反馈

安装版日志位于应用用户数据目录的 `logs/backend.log`，研究记录位于项目 `.merak/`。反馈时附软件版本、失败节点和相关日志片段，删除密钥及个人信息。
