# 论文一致性修订边界

独立一致性审查检查正文、引用、图表、数值来源和证据范围，返回结构化结论与问题。
程序只接受明确的 verdict，不能从“没有严重问题”等自由文本推断通过。

## 问题归属

- 章节措辞或科学解释问题：交给对应章节作者，限制到明确的源文件。
- 生成表格、图注或布局问题：交给实际生成器；不能要求包含该图表的章节作者
  修改生成结果、原始数据或来源摘要。
- 方法组成表描述声明的设计意图，不自动证明实现与机制已被独立验证。
- 点估计、预设范围和实际统计区间使用不同的来源说明，不借图表排版提升证据强度。

同一报告中的多个问题集中处理；修订后重新审查当前产物。问题没有解决时保持
未通过，模型自述、文件大小变化和活动心跳不能单独证明修订有效。

## 科研与展示的区别

正确披露的范围限制不要求捏造补充实验。真实的数值矛盾、引用错误和证据越界
仍属于必须修复的问题。可审查草稿与投稿就绪分别记录，不能互相推导。

显示文本和结构化响应的回归检查覆盖结论解析、生成表格归属、章节路径、
误判防护与恢复。实际发布状态见 [版本说明](RELEASE_0.1.1.md)，完整稳定性
要求见 [验收门槛](STABILITY_ACCEPTANCE.md)。
