# 0.1.2 修复公开测试版

本版在已发布的 0.1.1 基础上交付工作流与恢复修复，保留原界面和 13 节点流程。
旧版 v0.1.1 的标签和 Release 保留，不覆盖其安装包。
发布工作流新增构建前检查：版本或标签已存在时提前停止，避免完成构建后才发现冲突。

## 本版修复

- 实现修订保留独立审查问题、证据与写入范围；静态通过不再掩盖待处理审查意见。
- 任务尝试保存执行前约束和执行后校验；预算耗尽后的已完成编辑交独立复核，恢复不重复编辑。
- 修正复杂关系图布局、长标签与论文放大字号的尺寸适配。
- 论文候选章节及其引用统一使用候选文件视图，避免误读尚未提交的正式文件。
- 同一图表的无变化登记不再旋转清单时间戳，避免使已完成的审稿、审计无故失效。
- 审查意见可以被来源证据推翻；新问题在原任务预算内获得修订机会，保留失败和尝试记录。

## 已有真实模型验证

2026-11-01，一个 EEG 研究项目完成原运行的恢复交付，全部 13 个节点接受，
产出 20 页论文 PDF、LaTeX 源稿、18 页演示 PDF、可编辑 LaTeX、讲稿与审查记录。
最后一次冻结源码恢复耗时约 33.7 分钟，期间未改软件源码或手工补研究产物。

该项目选择“不执行真实实验”和“合成预览”。预览数字来自确定性构造，并非
实际训练方法与基线所得的 EEG 效果；不能用它证明科学结论或真实实验能力。
最终科研评分为 6/10，论文超过配置的 10–12 页软目标，不具备投稿就绪资格。

以下安装检查来自版本号调整前的本地修复候选（当时标记 0.1.1），不属于旧版已发布包，
也不能替代 0.1.2 的构建检查。2026-11-01，该 Windows x64 候选完成安装与文件一致性检查：
2,209 个安装文件与构建目录一致。随包后端、94 个技能、绘图、桌面认证、
工作流与聊天连接及重连、设置落库检查通过；隔离用户目录中的真实模型连接、
已有论文与演示 PDF 预览通过。取消与检查点恢复使用临时任务夹具验证，
不等于安装包完成了一次新的真实科研工作流。

此前开发候选另有实际 CPU 模拟计算记录；这些历史结果不代表当前安装包或
任意新任务已完成验证。随本次构建分发的 `package-smoke.json`、
`desktop-smoke.json`、`resume-smoke.json` 和 `build-info.json` 才是对应包的基础检查记录。

## 尚未满足的正式稳定版门槛

完成的研究任务经过开发修复与恢复，不是同一冻结版本三个新项目连续无干预
成功的证明。模型网关曾返回 HTTP 502、503 和超时，恢复仍受服务可用性和预算约束。
未完成任意旧版本升级迁移、所有外部服务和 GPU 环境验收。

自定义 LaTeX 图片宏可能触发缺图误判，当前可通过明确的图片引用路径修订。
论文页数控制、跨领域新任务成功率、长上下文效率仍需改进。
软件内置后端运行环境；LaTeX 编译和真实科研实验仍需相应外部工具、依赖与数据。

科研交付是可审查草稿，保留审稿与审计中的科学限制，不表示具备投稿资格。
验证论文超过原目标页数。请勿把本版本标为工业级稳定性验收已全部完成。

安装器和校验文件作为 GitHub Release 附件分发，不提交到源码 Git 历史。
具体构建步骤见 [发布指南](RELEASING.md)，稳定性门槛见
[稳定性验收](STABILITY_ACCEPTANCE.md)。
